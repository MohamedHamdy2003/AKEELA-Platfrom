# AKEELA APIs

Open this folder as a Bruno collection. Choose Local or Production.

- Only implemented APIs are included, in numbered feature folders matching the project docs.
- Select **Local** (`http://localhost:3000/api/v1`) or **Production** (`https://api.akeelaonline.tech/api/v1`), then enter `email`, `phone`, `full_name`, and the secret fields (`password`, `new_password`, `verification_otp`, `reset_otp`) directly in Bruno's Environment panel.
- Read email OTPs manually. Login/Refresh store tokens in runtime memory; do not commit real credentials or tokens.
- Run requests individually, not the whole collection as one automated flow.
- Pull main to receive released API updates.

See the project guide at `docs/BRUNO.md` in the repository root.
